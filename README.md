# Site da Congregação IPRB em Tijucas (SC)

Site estático demonstrativo para a Congregação da Igreja Presbiteriana Renovada do Brasil em Tijucas, Santa Catarina, criado com **HTML5, CSS3 e JavaScript puro** e usando o logotipo enviado.

> **Atenção:** todos os dados locais, como endereço, horários, telefone, e-mail e ministérios, são fictícios para facilitar a personalização. Substitua-os antes de publicar. Este projeto não é o site oficial nacional da IPRB.

## Recursos
- Página inicial e apresentação da congregação.
- Programação de cultos e encontros.
- Área para mensagens, vida comunitária e ministérios.
- Endereço demonstrativo, link de mapa e contato.
- Menu móvel, navegação por seções, animações suaves e botão voltar ao topo.
- Layout responsivo para celular, tablet e desktop.

## Estrutura
```text
iprb-site-estatico/
├── index.html
├── README.md
└── assets/
    ├── css/style.css
    ├── js/script.js
    └── img/logo-iprb.png
```

## Executar localmente
1. Extraia o ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` diretamente no navegador ou use a extensão Live Server.
4. Teste o menu e os links em desktop e celular. Não é necessário instalar dependências.

## Personalizar antes de publicar
1. Abra `index.html` e pesquise por `fictício`, `Rua das Oliveiras`, `5548999999999` e `19h` para localizar dados demonstrativos.
2. Atualize endereço, horários, telefone/WhatsApp, e-mail e nome dos ministérios.
3. Substitua os elementos gráficos ilustrativos por fotos autorizadas da congregação.
4. Revise o conteúdo e confirme autorização para uso do logotipo.
5. Confira todos os links e teste o site em vários tamanhos de tela.
